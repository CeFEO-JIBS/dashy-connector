Add Dashy to Claude

The connector is a remote MCP server. You add it once in Claude's settings, then enable it in any conversation. Here is the URL you will need:

MCP Server https://mcp.fbdashboard.org/mcp

That is all you need. There is also an optional Dashy skill you can add afterwards — it shapes how Claude answers with the data.

Pick your plan

Pro & Max

Individual accounts
  1. Open Settings → Connectors.
  2. Click Add custom connector.
  3. Paste the MCP server URL above.
  4. Name the connector Dashy.
  5. Click Add, then sign in when prompted.

Team & Enterprise

Managed by an owner
  1. An Owner opens Organization settings → Connectors.
  2. Chooses Add custom connector.
  3. Pastes the URL and names the connector Dashy.
  4. Saves it for the organisation.
  5. Each member then connects individually and signs in.

Custom connectors are a Claude feature on Pro, Max, Team and Enterprise plans. The remote MCP server URL must use HTTPS — Dashy already does. New connectors are added from the web app or desktop app; the mobile apps can use a connector you have already added, but cannot add new ones.

Step by step

Open Connectors in settings

On Pro or Max, go to Settings → Connectors. On Team or Enterprise, an Owner does this under Organization settings → Connectors.

Add a custom connector

Click Add custom connector at the bottom of the Connectors section, then paste the Dashy MCP server URL:

https://mcp.fbdashboard.org/mcp

Name the connector Dashy so it is easy to recognise later. You can leave the transport and icon fields at their defaults, then click Add.

Sign in to authorise

Claude will open a sign-in step to authorise the connection. This grants Claude read access to the research dataset on your behalf — Claude never sees your password, and you can revoke access at any time by disconnecting the connector.

Allow Dashy's tools

Open Dashy under Settings → Connectors. In Tool permissions you will see Dashy's eight tools. Set them to Always allow so Claude can search the dataset without asking for approval on every question.

Enable it in a conversation

In a chat, use the + button near the message box, open Connectors, and switch on Dashy. Connectors are toggled per conversation, so you decide when Claude can reach the dataset.

Try a first question

Ask something the dataset can answer, for example:

Dashy, what family business research says about board
of directors? What are the main themes and the key
references?

If Claude returns the main themes with specific references, the connector is working.

Note: start your questions by addressing Dashy directly — for example, “Dashy, what do we know about…”

Optional · Add the Dashy skill

Give Claude Dashy's research manners

The connector gives Claude the data. The skill gives Claude the method: report the state of the evidence rather than advise, name the theoretical lens behind a finding, cite only papers actually returned by the connector, and say so plainly when the evidence is thin. It is a small text file you upload once to your own Claude account. The connector works without it — the skill only changes how the answers read.

Download the skill (.zip) Read it first

Uploaded skills are private to your own account. Nothing is shared with us, and you can read the whole file before you install it.

Download the file

Use the button above. You get dashy-connector-skill.zip — keep it zipped, Claude expects the zip.

Open Skills in settings

Go to Settings → Capabilities → Skills. Depending on your plan and app version the section may be called Features or sit under Customize. Skills sit inside Claude's code-execution capability, so if you cannot find the section, switch on Code execution and file creation first.

Upload and switch it on

Choose Upload skill, select the zip, and toggle dashy-connector on. Custom skills are available on Pro, Max, Team and Enterprise, and each person uploads their own copy — there is no organisation-wide rollout for skills, unlike the connector.

Address Dashy by name

With the connector enabled in the conversation, start your question with Dashy's name. The skill loads on its own from there.

Dashy, what does the research say about succession
in family firms, and where do the findings disagree?

If the connector is off, the skill will tell you so and stop rather than answer from general knowledge. That is deliberate.

Can a link install it for you? Not today. Claude has no “install this skill” link that a website can trigger — a skill is added in your own account settings, and nothing on this page can reach into them. The download button above is the shortest honest path. It also means you can read the file before installing it, which is worth doing for any skill you get from the internet.

Using Claude Code? Skills there are plain files on your machine. One line installs it:

mkdir -p ~/.claude/skills/dashy-connector && curl -fsSL \
  https://claude.fbdashboard.org/skill/dashy-connector/SKILL.md \
  -o ~/.claude/skills/dashy-connector/SKILL.md

Then add the connector with claude mcp add --transport http Dashy https://mcp.fbdashboard.org/mcp and restart the session.

If something is off
The connector doesn't appear in my chat ›

Connectors are enabled per conversation. Open the + menu near the message box, choose Connectors, and toggle Dashy on. On Team and Enterprise plans, an Owner must add the connector for the organisation before members can see it.

I can't add a connector ›

Custom connectors are available on Pro, Max, Team and Enterprise. They are added from the web or desktop app, not from the mobile apps. If you are on a Team or Enterprise plan, only an Owner can add a new connector.

Sign-in failed or I need to reconnect ›

Remove the connector in Settings → Connectors and add it again with the URL above. If the sign-in step still fails, the dataset may be in a maintenance window — get in touch and we'll check.

I uploaded the skill but Claude doesn't sound like Dashy ›

Check three things: the skill is toggled on under Settings → Capabilities → Skills, the Dashy connector is switched on in that particular conversation, and you addressed Dashy by name in your question. A skill loads when the question matches what it is for, so “Dashy, what does the research say about…” is the reliable opening.

Can I send the skill to Claude with one click? ›

No. A skill is installed in your own account settings, and no website — including this one — can write there on your behalf. Download the zip and upload it yourself; it takes about as long as adding the connector did. The upside is that you can read the file first, which is a good habit for any skill you get from the internet.

I'm being rate-limited ›

Access is paced per user to keep capacity fair during the pilot. For larger or systematic searches, reach out and we'll talk through options.
